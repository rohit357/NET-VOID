Welcome to NET-VOID

Interactive network simulator — visualize and control a fictional internet topology in real time.

What you can do

  • Spawn nodes — Create servers, APIs, databases, websites, users, and networks
  • Connect — Link nodes to build routing paths
  • Send requests — Watch packets travel across the network with realistic latency
  • Monitor — Track requests/sec, latency, packet loss, and node health
  • Chaos mode — Randomly inject failures, latency spikes, and overloads

Controls

  • Select tool — Click nodes to inspect. Drag to move. Drag empty space to pan.
  • Connect tool — Click two nodes to link them
  • Send request tool — Click source, then destination
  • Mouse wheel — Zoom in/out

Visual feedback

  • Pulsing glow — Ambient activity on healthy nodes
  • Bright flash — Node sending or receiving a request
  • Moving dots — Packets traveling between nodes
  • Color rings — Node status (yellow = overloaded, red = failed)
